# 2D Mobile Game Project

2D 모바일 게임 개발자 인턴 과제 전형으로 제작한 프로젝트입니다.  
‘TDS - 타워 데스티니 서바이브’ 게임을 참고하여, 이동하는 타워 앞에 쌓이는 몬스터의 구현을 목표로 했습니다.

> 참고 게임 링크: [TDS - Google Play](https://play.google.com/store/apps/details?id=com.playstrom.hero.tower&hl=ko)

---

## 주요 구현 내용

- **FSM(Finite State Machine)**을 이용하여 적 캐릭터의 움직임 상태 구현
- 추후 타워 구매 시스템 확장을 고려해 **Object Pooling**으로 타워를 미리 생성  
  (최대 개수에 맞춰 생성하고 가장 위에 플레이어 배치)
- 플레이어와 적이 **타겟을 추적**하여 자동 공격을 수행하는 시스템 구성
- 한번에 여러 공격을 동시에 받았을 때 데미지가 너무 자주 출력되서 시인성이 낮아지는것을 확인.
   -> 일정 시간 마다 그 전에 받은 데미지를 합산해서 출력하는 방식으로 해결
- 2D 환경에서 3D 처럼 3열로 나오는 몬스터 구현에 어려움을 겪음
   -> Layer를 분리하고 각 레이어 마다 충돌을 다르게 처리 하는 방식으로 3열로 오는 몬스터 구현
